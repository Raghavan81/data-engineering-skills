# Data Engineering Skills

A collection of Databricks data engineering skills and workflows, designed for integration into various AI agent frameworks or development environments.

## Skills Included

### 1. Data Engineering Databricks Pipeline
- **Location:** `data-engineering-databricks-pipeline/`
- **Description:** Comprehensive skill for designing, developing, and migrating ETL/data pipelines on Databricks
- **Features:**
  - Net-new development and migration support
  - Multi-feed and multi-BRD handling
  - RAG-based context retrieval
  - Genie Code/Spaces backend routing
  - Parameterized workflow generation
  - Manual code change detection
  - Versioned HTML audit and efficiency reporting
  - Job-level state resumability

### 2. Databricks QA Pipeline
- **Location:** `databricks-qa-pipeline/`
- **Description:** Interactive skill for generating automated QA pipelines on Databricks
- **Features:**
  - QA pipeline automation
  - Integration testing support
  - UAT workflows

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/Raghavan81/data-engineering-skills.git
   cd data-engineering-skills
   ```

2. Copy the skill directories to your preferred location (e.g., your project directory or your IDE's skills/plugins folder):
   ```bash
   cp -r data-engineering-databricks-pipeline /path/to/your/skills/
   cp -r databricks-qa-pipeline /path/to/your/skills/
   ```
   ```

## Usage

Refer to the individual SKILL.md files within each directory for detailed usage instructions. These skills are designed to be integrated into various AI agent frameworks and development environments, including but not limited to Databricks Genie, and custom IDE implementations.
